# Soukhya Riverside Homestay 🌿

A peaceful riverside homestay website built for Soukhya Riverside Homestay, located in Aghanashini near Gokarna, Karnataka.

The website focuses on:
- Sunrise & sunset experiences
- Riverside slow-living atmosphere
- Direct WhatsApp bookings
- Modern responsive design
- Premium yet authentic homestay branding

---

## ✨ Features

- Cinematic fullscreen hero section
- Responsive modern UI
- Dynamic booking fare calculator
- WhatsApp booking integration
- Masonry-style image gallery
- Lazy-loaded images for performance
- Testimonials & trust indicators
- Mobile sticky booking CTA
- Google Maps integration
- SEO-friendly meta tags
- Smooth animations & transitions

---

## 🌅 Experience Highlights

- Riverside sunrise views directly from the stay
- Famous sunset viewpoint nearby
- Dolphin watching & boating
- Ferry rides & beach experiences
- Peaceful village atmosphere near Gokarna
